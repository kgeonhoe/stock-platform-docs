# stock-platform dbt docs

Auto-published dbt documentation site for [stock-platform](https://github.com/kgeonhoe/stock_platform_server) (private repo).

Live site: https://kgeonhoe.github.io/stock-platform-docs/

Content is regenerated by a Dagster asset (`dbt_docs_site`) after every dbt build and pushed here automatically. Only lakehouse staging model SQL, schema/column metadata, and lineage are included — no application/trading logic.
